One line, at most 120 characters: the funniest out-of-office auto-reply a houseplant would send.

> Thank you for your email. I'm away from my pot, photosynthesizing by the window. I'll reply once watered — so, never.

Run it with Node 22.18+:

```sh
node main.ts
```

It prints the line to stdout and writes it to `/output/entry.txt`.
